# 🛡️ Bunker Advisor

**URL:** [https://bunkeradvisor.github.io/](https://bunkeradvisor.github.io/)

---

## 🧭 Project Overview

**Bunker Advisor** is a simple, dark-themed, and **mobile-responsive** web utility designed to streamline the research process for purchasing custom survival bunkers in the United States.

It helps users generate a comprehensive, ready-to-use **AI prompt** that compares key providers across specific US states.

---

## ✨ Key Features

* **State Selection:** Easily choose any US state to localize your bunker research.
* **AI Prompt Generation:** Creates a detailed query covering **20 top companies**, typical models, base/additional pricing, lead times, demo locations, and common user issues.
* **Direct AI Links:** One-click buttons to launch the generated prompt directly in **ChatGPT, Gemini, and Copilot**.
* **Thematic Design:** Dark theme optimized for readability and a "shelter" aesthetic.
* **SEO Optimized:** Enhanced meta-tags and semantic structure for better discoverability.

---

## 🚀 How to Use

1.  Visit the live page: [Bunker Advisor](https://bunkeradvisor.github.io/).
2.  Select the **U.S. state** where you plan to build a bunker.
3.  The detailed AI prompt will be generated automatically in the box below.
4.  Click the **"Copy Prompt"** button or select your preferred AI assistant (**ChatGPT, Gemini, or Copilot**) to start your research immediately.
